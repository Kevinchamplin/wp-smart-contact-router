# WP Smart Contact Router

A modern WordPress plugin that routes contact form submissions to different recipients based on topic and priority.

## Highlights

- PHP 8 with `strict_types` and namespaced, PSR-4 class structure.
- Shortcode-driven contact form: `[smart_contact_router]`.
- Secure submission handling via `admin-post.php`, nonces, and sanitization.
- Pluggable routing: per-topic recipient addresses stored in WordPress options.

## Usage

1. Place the plugin folder inside `wp-content/plugins/wp-smart-contact-router`.
2. Activate **WP Smart Contact Router** in the WordPress admin.
3. Add the shortcode `[smart_contact_router]` to any page.
4. Configure routing options via code or (later) an options screen.
